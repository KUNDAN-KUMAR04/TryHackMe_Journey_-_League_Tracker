How to Host & Update on GitHub Pages

Step 1: Initial Setup in 1 Minute

  1. Create a new public repository on GitHub (e.g. thm-journey).
  2. Upload this file as index.html.
  3. Click the "Export users.json" button in the top menu bar, and save it in the root of your repository as users.json.
  4. In GitHub: Go to Settings → Pages → Branch: main → Save. Your site is live!

Step 2: How to Add Users in the Future Without Touching Any Code

Option A (Web-Only): Add users anytime directly using the website UI. Then click "Export users.json" and commit/upload that single file to GitHub.

Option B (Direct in GitHub): Go to your repository on GitHub.com, click on users.json, click the pencil icon (), paste new entries in the clean JSON format, and click Commit Changes!
